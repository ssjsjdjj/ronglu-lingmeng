# 熔炉灵萌 · 山间消消乐

受《沧元图》熔炉山小兽小队启发的三消玩法原型。角色头像参考原片截图通过 ImageGen 重绘，并使用带透明通道的 WebP 素材，技能和五个关卡为本原型的玩法设计。

## 本地运行

需要 Node.js 20 或更高版本，无需安装依赖。

```sh
node server.mjs
```

浏览器打开 http://127.0.0.1:4319/ 。如端口被占用，可通过 PORT 环境变量指定其他端口。不要直接以 file:// 打开 index.html，因为浏览器会限制 JavaScript 模块。

```sh
node --test tests/engine.test.mjs tests/systems.test.mjs
```

## 已实现

- 8×8 三消棋盘，鼠标点按、手指滑动、键盘操作。
- 初始无自动消除且有合法走法；无效交换不扣步数；死局自动重排。
- 四消生成横向或纵向雷光，五消生成灵珠，T / L 形生成爆破；特效可连锁触发。
- 孟川、晏烬、姬元通、千木、黑水鲶鱼、紫狐一枝梅六种角色技能，共享 48 点小队灵力；技能不扣步数。
- 五关冒险，收集、分数、单层和双层冰晶目标；最后一步达成目标仍然算通关。
- 随心模式不限步数，失败免费重试；提示不限次，冒险每关可主动重排两次。
- 通关星级、解锁进度、当前棋盘、已用重排次数、角色及音效偏好保存于当前浏览器。
- 合成音效、移动端布局、减少动态效果偏好支持，无广告、无支付、无体力限制。

## 文件

- `dist/engine.js`：独立的消除和关卡结算逻辑。
- `dist/app.js`：输入、动画、声音、弹窗和本地存档。
- `dist/art.js`：角色图标、称呼、技能文案。
- `dist/style.css`：场景、棋盘及响应式布局。
- `tests/engine.test.mjs`：结算、角色技能与随机棋盘测试。

游戏逻辑与美术均在本地文件中。中文网页字体是可选的在线资源，加载失败时使用系统字体，玩法仍可运行。清除浏览器站点数据会删除本机存档。

## 原型边界

当前为单人浏览器游戏，没有账号云存档、多人玩法或微信小游戏平台接入。角色依据熔炉山小兽形态生成重绘；原始 PNG 和制作提示词保存在 art-source/，网页优化素材在 dist/assets/。动作采用四帧精灵图与程序特效组合。体验是否优于成熟三消产品需要通过真实试玩反馈、关卡平衡和反复迭代评估。

## 2026-11-11 角色更新

五位角色的毛色、眉纹、眼周纹、耳环、项坠和鲶鱼须鳍参考原片重绘。黑水鲶鱼替代原棋盘灵叶，六种棋子总数不变，旧棋盘和关卡解锁进度可继续使用。新增第五位出战角色黑水，技能「黑水涌流」清除冰晶最多的两整列，不扣步数；第五关改为收集黑水鲶鱼。右上角书本按钮打开角色图鉴。

## V3：灵契、连携与守关战

- 每局开场选择一种灵契：灵涌将主动技能消耗降为 36；回春每消除 20 格返还 1 步，最多 3 步；破阵赠送一颗爆破，并强化特效和技能的破冰能力。
- 主动技能后有 3 个有效交换的连携窗口，换一位角色可免费追击，每局最多 2 次。孟川与晏烬触发霜雷十字与额外破冰，姬元通与千木触发区域爆破并留下爆破棋子，黑水与其他角色清除双对角线。其余搭配为十字合击。连携不扣灵力和步数。
- 棋盘下方有独立的「守关挑战」入口，无需解锁普通关卡。第三、第五关也有守卫。守卫 4 个有效交换后冻结紫色预告格；消除预告格削弱攻击，单次至少 4 格、2 次连锁或角色技能／连携可打断蓄力。击退后不再冻结，但仍需完成本关收集、灵力与清空冰晶目标。
- 守关挑战的最佳成绩独立保存，不改变冒险的关卡解锁。灵契、连携剩余窗口、守卫气血、蓄力、预告位置和随机数状态都可恢复。旧版本进行中的棋盘保持原有难度，新玩法可从独立挑战或新开局进入。
- `dist/strategy-ui.js` 管理战斗状态卡、连携按钮与灵契选项。`tests/systems.test.mjs` 覆盖新增规则，与原有测试合计 36 项。
- `npm run balance` 是能够观察全部候选结算的自动对局检查，只验证增益组合可通关，不代表真人难度或试玩评价。

## V4：角色动作与技能反馈

- 五位角色各有待机、眨眼（千木为眨单眼）、蓄力、出招四帧透明素材。棋盘上有呼吸、轻摆、选中跳动、落地回弹；孟川突进挥爪配雷光，晏烬跃起施霜，姬元通炸毛拍爪配冲击波，千木施法配残影与灵叶，黑水摆动配水柱与气泡。双人连携同时出现两位角色。
- 原火苗棋子替换成姬元通炸毛表情，带「怒」角标；原姬元通棋子为冷脸。仍为六类棋子，两种表情分别匹配，旧存档无需迁移。
- 消除增加缩放爆开、分角色粒子、分数浮字、雷光光束、爆破冲击环、灵珠彩色波纹与轻微震动；连锁递进音效遵循右上角静音开关。
- 右上角角色图鉴可点击「动作试演」，观看五位角色的动作特效，不改变棋盘、分数、灵力或步数。
- 手机端限制粒子数量；空闲时停止粒子绘制。尊重系统「减少动态效果」设置，关闭粒子与震动，缩短技能展示。
- `dist/sprites.js` 管理精灵标记，`dist/motion.css` 管理帧与动作，`dist/juice.js` 管理粒子、技能展示和音效。`art-source/*-atlas-v4.png` 为原始四帧素材，`dist/assets/*-atlas-v4.webp` 为网页素材；`art-source/animation-prompts-v4.json` 保存内置 ImageGen 的完整提示词。
- 验证：36 项玩法测试通过；浏览器实测五种试演保持棋盘与计数不变、实际技能与双人连携不扣步数；390 / 360 像素手机视口无横向溢出，控制台无错误。

## V5：紫狐「一枝梅」

- 按用户确认，将棋子类型 5 从「姬元通·炸毛」替换成紫狐「一枝梅」，移除「怒」角标。姬元通仍为黑猫，千木仍为橘红狐狸；棋盘保持六类，旧棋盘的类型、位置、特效和解锁记录可继续使用。
- 一枝梅作为第六位可出战伙伴，拥有待机、眨眼、蓄力与抬爪四帧素材，以及呼吸轻摆、跃起施法和狐影残像。角色切换区改成两行，图鉴可免费试演。
- 主动技能「紫梅幻阵」清除冰晶总层数最多的一行与一列（十字 15 格），无冰晶时使用中间十字。共享小队灵力，不扣步数。技能和连携属于本原型设计。
- 一枝梅与其他角色的连携为「紫梅同心」：十字消除并额外破一层冰，沿用连携窗口与次数限制。新增角色的选择、连携来源和随机状态均可恢复。
- 紫狐消除使用紫色花瓣粒子；施法加入紫色十字光束、六瓣旋转法阵、冲击光环、狐影和专属递进铃音。静音与系统减少动态效果设置继续生效。
- `art-source/yizhimei-atlas-v5.png` 是内置 ImageGen 生成的透明四帧原图，`dist/assets/yizhimei-atlas-v5.webp` 是网页素材，`art-source/yizhimei-prompts-v5.json` 保存完整提示词与角色参考来源。
- 验证：40 项玩法测试通过，包含新技能目标、灵力阈值、双向连携、额外破冰和存档恢复；浏览器实测试演不改变棋盘与计数、实战施法、双人同场、刷新恢复，360 像素手机视口无横向溢出，控制台无错误。

## V6：独立摆尾与甩尾幻阵

- 紫狐拆成无尾身体四帧与独立蓬尾图层。尾巴以根部为轴连续左右摆动，在棋盘、出战区和图鉴中均可见；施法时经历卷尾蓄力、大幅甩尾、回弹收势。尾巴与面部帧独立播放，连携中的紫狐也有相同动作。
- 甩尾时先扫出紫金弧形光轨，再展开多层符环与十字光束，最后出现螺旋花瓣、光点和扩散冲击环。音效分为蓄力、甩尾风声和命中铃音，按命中时机触发。一次紫狐技能展示约 1.3 秒，图鉴试演约 1.5 秒。
- `dist/tail-motion.css` 管理独立尾巴和甩尾动作；`dist/juice.js` 管理分阶段光效。手机继续限制粒子数量，减少动态效果偏好下尾巴保持静止，关闭复杂光效。
- 内置 ImageGen 原图为 `art-source/yizhimei-body-atlas-v6.png`、`art-source/yizhimei-tail-v6.png`；网页素材位于 `dist/assets/`，完整提示词在 `art-source/yizhimei-tail-prompts-v6.json`。
- 验证：40 项玩法测试通过。浏览器录得独立摆尾与甩尾不同姿态；试演保持棋盘及计数不变；实际技能正常结算并解除忙碌状态；双人连携的紫狐可甩尾，其他角色技能仍正常播放。360 像素手机视口无横向溢出，控制台无错误。

- 孟川、晏烬、姬元通、千木各拆成四帧身体、左耳、右耳与尾巴。白兔为短绒球尾，狼为黑白蓬尾，黑猫为细长尾，橘狐为白尖大尾；耳环随橘狐耳朵一起活动。黑水独立控制左右鳃鳍、两根长须和背鳍。五位角色共 17 个独立部件，在棋盘、角色栏和图鉴中持续活动；紫狐原有分层摆尾保留。
